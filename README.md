# Civil Engineer Portfolio Website

## 📌 Project Overview
This is a personal portfolio website created for a Civil Engineer with 5 years of professional experience. The website is designed to showcase work experience, skills, and professional background in a clean and simple format.

---

## 🎯 Purpose
The main purpose of this project is to present a professional online portfolio for a civil engineer, highlighting experience in different construction companies and projects.

---

## 🏗️ Features
- Professional portfolio design
- Experience section with company history
- Skills and qualifications showcase
- Responsive layout (mobile + desktop)
- Simple and user-friendly UI

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

- This is a simple Portfolio

---

## 👤 About the Portfolio Owner
This portfolio represents a Civil Engineer with 5 years of experience in different construction companies and site management roles.

Completed and uploaded for demonstration purposes.
